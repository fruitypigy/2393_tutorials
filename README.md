# 2393_tutorials

Training tutorials for Team 2393. The content lives in this repository's **[Wiki](https://github.com/fruitypigy/2393_tutorials/wiki)**.

## Editing the wiki locally

```bash
git clone https://github.com/fruitypigy/2393_tutorials.wiki.git
```

Pages are Markdown files at the top level of the wiki repo. Screenshots go in `images/` and are referenced with relative paths, e.g. `![Smiley part](images/smiley-part.png)`.
